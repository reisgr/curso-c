2.1 Variáveis e Tipos de Dados

💾 O que é uma Variável?

Uma variável é um espaço na memória do computador onde podemos armazenar dados. Cada variável tem um nome, um tipo e um valor.

Pense em uma variável como uma caixa rotulada onde guardamos algo. A etiqueta é o nome, o tipo de coisa que guardamos é o tipo de dado, e o que está dentro é o valor.

📝 Declarar uma Variável

A sintaxe básica para declarar uma variável é:

tipo nome_da_variavel;

Exemplos:

int idade;
float altura;
char letra;

🎯 Declarar e Inicializar

Podemos declarar e atribuir um valor na mesma linha:

int idade = 25;
float altura = 1.75;
char letra = 'A';

📋 Regras para Nomes de Variáveis

  • Começar com letra ou underscore (_)
  • Conter apenas letras, números e underscore
  • NÃO podem conter espaços
  • NÃO podem ser palavras-chave do C (int, float, if, etc.)
  • C distingue maiúsculas de minúsculas (idade ≠ Idade)

Exemplos válidos: idade, _peso, altura2, minha_idade

Exemplos inválidos: 2altura, minha idade, int (palavra-chave)

💡 Dica de Nomeação: Use nomes descritivos e em snake_case (separado por underscore). Por exemplo: idade_usuario é melhor que i ou a.

🔄 Atribuição de Valores

int numero;        // Declaração
numero = 42;       // Atribuição
numero = 100;      // Pode ser alterado (reatribuição)

2.2 Tipos de Dados Primitivos

C possui vários tipos de dados primitivos. Os mais comuns são:

📊 Tabela de Tipos

Tipo Tamanho Intervalo Exemplo
int 4 bytes -2.147.483.648 a 2.147.483.647 int idade = 25;
float 4 bytes ±3.4 × 1038 float altura = 1.75;
double 8 bytes ±1.7 × 10308 double pi = 3.14159265;
char 1 byte -128 a 127 char letra = 'A';
short 2 bytes -32.768 a 32.767 short numero = 100;
long 8 bytes Muito grande long numero = 1000000L;

🔤 Tipo int (Inteiro)

Armazena números inteiros (sem casas decimais):

int idade = 25;
int temperatura = -10;
int resultado = 0;

🔢 Tipo float (Ponto Flutuante)

Armazena números com casas decimais (precisão simples):

float altura = 1.75;
float peso = 72.5;
float pi = 3.14;
⚠️ Atenção: Em C, use ponto (.) como separador decimal, não vírgula!

📈 Tipo double (Ponto Flutuante Dupla Precisão)

Como float, mas com mais precisão (8 bytes):

double pi_preciso = 3.14159265359;
double distancia = 1234567.89;

🔤 Tipo char (Caractere)

Armazena um único caractere entre aspas simples:

char letra = 'A';
char simbolo = '@';
char numero = '7';  // '7' é diferente de 7!
Importante:
  • 'A' (entre aspas simples) é um char
  • 65 é um inteiro (valor ASCII do 'A')
  • "A" (entre aspas duplas) é uma string

📏 Verificar Tamanho

Use o operador sizeof para saber quantos bytes cada tipo ocupa:

#include <stdio.h>

int main() {
    printf("int: %lu bytes\n", sizeof(int));
    printf("float: %lu bytes\n", sizeof(float));
    printf("double: %lu bytes\n", sizeof(double));
    printf("char: %lu bytes\n", sizeof(char));
    
    return 0;
}

Saída esperada:

int: 4 bytes
float: 4 bytes
double: 8 bytes
char: 1 byte

2.3 Operadores

➕ Operadores Aritméticos

Operador Descrição Exemplo Resultado
+ Adição 10 + 5 15
- Subtração 10 - 5 5
* Multiplicação 10 * 5 50
/ Divisão 10 / 5 2
% Módulo (resto) 10 % 3 1

Exemplo:

int a = 10, b = 3;
int soma = a + b;        // 13
int diferenca = a - b;   // 7
int produto = a * b;     // 30
int quociente = a / b;   // 3
int resto = a % b;       // 1
💡 Dica: O operador % (módulo) é muito útil para verificar se um número é par ou ímpar!

🔗 Operadores de Atribuição

Operador Equivalente a Exemplo
= Atribuição simples a = 5;
+= a = a + b a += 5; (a = a + 5)
-= a = a - b a -= 5; (a = a - 5)
*= a = a * b a *= 5; (a = a * 5)
/= a = a / b a /= 5; (a = a / 5)

🔢 Operadores Relacionais

Usados para comparar valores. Resultam em verdadeiro (1) ou falso (0):

Operador Descrição Exemplo Resultado
== Igual 5 == 5 1 (verdadeiro)
!= Diferente 5 != 3 1 (verdadeiro)
< Menor que 3 < 5 1 (verdadeiro)
> Maior que 5 > 3 1 (verdadeiro)
<= Menor ou igual 5 <= 5 1 (verdadeiro)
>= Maior ou igual 5 >= 3 1 (verdadeiro)

⚡ Operadores Lógicos

Operador Descrição Exemplo Resultado
&& E (AND) 5 > 3 && 2 < 4 1 (verdadeiro)
|| OU (OR) 5 > 10 || 2 < 4 1 (verdadeiro)
! NÃO (NOT) !(5 > 10) 1 (verdadeiro)

Exemplos:

int a = 10, b = 5, c = 3;

// AND - precisa que AMBAS sejam verdadeiras
if (a > b && b > c) {  // 10 > 5 E 5 > 3 = verdadeiro
    printf("Ambas são verdadeiras\n");
}

// OR - precisa que UMA seja verdadeira
if (a < b || b > c) {  // 10 < 5 OU 5 > 3 = verdadeiro
    printf("Pelo menos uma é verdadeira\n");
}

// NOT - inverte o resultado
if (!(a < b)) {        // NÃO (10 < 5) = verdadeiro
    printf("a NÃO é menor que b\n");
}

2.4 Entrada e Saída de Dados

📤 Função printf() - Exibir na Tela

Já conhecemos printf(), vamos ver com mais detalhes:

printf("texto com %tipo", variavel);

📋 Especificadores de Formato

Especificador Tipo Exemplo
%d ou %i int printf("%d\n", 42); → 42
%f float ou double printf("%f\n", 3.14); → 3.140000
%.2f float (2 casas decimais) printf("%.2f\n", 3.14159); → 3.14
%c char printf("%c\n", 'A'); → A
%s string printf("%s\n", "Olá"); → Olá

Exemplos:

#include <stdio.h>

int main() {
    int idade = 25;
    float altura = 1.75;
    char inicial = 'J';
    
    printf("Idade: %d\n", idade);
    printf("Altura: %.2f\n", altura);
    printf("Inicial: %c\n", inicial);
    
    return 0;
}

Saída:

Idade: 25
Altura: 1.75
Inicial: J

📥 Função scanf() - Ler do Teclado

scanf() lê dados que o usuário digita:

scanf("%tipo", &variavel);
⚠️ Importante: Note o símbolo & (endereço). Ele é necessário!

Exemplo completo:

#include <stdio.h>

int main() {
    int numero;
    float valor;
    
    printf("Digite um número inteiro: ");
    scanf("%d", &numero);
    
    printf("Digite um valor decimal: ");
    scanf("%f", &valor);
    
    printf("Você digitou %d e %.2f\n", numero, valor);
    
    return 0;
}

Exemplo de execução:

Digite um número inteiro: 42
Digite um valor decimal: 3.14
Você digitou 42 e 3.14

📝 Programa Completo - Calculadora Simples

#include <stdio.h>

int main() {
    int a, b, soma, diferenca, produto;
    
    printf("=== CALCULADORA SIMPLES ===\n");
    printf("Digite o primeiro número: ");
    scanf("%d", &a);
    
    printf("Digite o segundo número: ");
    scanf("%d", &b);
    
    soma = a + b;
    diferenca = a - b;
    produto = a * b;
    
    printf("\n=== RESULTADOS ===\n");
    printf("%d + %d = %d\n", a, b, soma);
    printf("%d - %d = %d\n", a, b, diferenca);
    printf("%d * %d = %d\n", a, b, produto);
    
    return 0;
}
💡 Dica: Sempre exiba uma mensagem antes de usar scanf() para instruir o usuário sobre o que digitar!

📝 Exercícios Práticos

Exercício 2.1: Idade em Dias
