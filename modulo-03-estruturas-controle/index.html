3.1 Estrutura if-else

🤔 O que é uma Estrutura de Controle?

Estruturas de controle permitem que o programa tome decisões baseadas em condições. Elas fazem o código seguir caminhos diferentes dependendo de se uma condição é verdadeira ou falsa.

📋 Estrutura if (Se)

Executa um bloco de código SE uma condição for verdadeira:

if (condição) {
    // Código executado se a condição for verdadeira
}

Exemplo:

#include <stdio.h>

int main() {
    int idade = 18;
    
    if (idade >= 18) {
        printf("Você é maior de idade\n");
    }
    
    return 0;
}

Saída: Você é maior de idade

📋 Estrutura if-else (Se-Senão)

Escolhe entre dois caminhos:

if (condição) {
    // Código se a condição for VERDADEIRA
} else {
    // Código se a condição for FALSA
}

Exemplo:

#include <stdio.h>

int main() {
    int idade = 15;
    
    if (idade >= 18) {
        printf("Você é maior de idade\n");
    } else {
        printf("Você é menor de idade\n");
    }
    
    return 0;
}

Saída: Você é menor de idade

📋 Estrutura if-else if-else (Se-Senão Se-Senão)

Escolhe entre múltiplos caminhos:

if (condição1) {
    // Executado se condição1 for verdadeira
} else if (condição2) {
    // Executado se condição1 for falsa E condição2 for verdadeira
} else if (condição3) {
    // Executado se condição1 e 2 forem falsas E condição3 for verdadeira
} else {
    // Executado se todas as condições anteriores forem falsas
}

Exemplo Completo - Classificação de Idade:

#include <stdio.h>

int main() {
    int idade;
    
    printf("Digite sua idade: ");
    scanf("%d", &idade);
    
    if (idade < 13) {
        printf("Você é uma criança\n");
    } else if (idade < 18) {
        printf("Você é um adolescente\n");
    } else if (idade < 60) {
        printf("Você é um adulto\n");
    } else {
        printf("Você é um idoso\n");
    }
    
    return 0;
}

Possíveis Saídas:

  • Digite sua idade: 10 → Você é uma criança
  • Digite sua idade: 16 → Você é um adolescente
  • Digite sua idade: 35 → Você é um adulto
  • Digite sua idade: 70 → Você é um idoso
FLUXOGRAMA if-else if-else Idade < 13? ├─ SIM → Criança └─ NÃO → Idade < 18? ├─ SIM → Adolescente └─ NÃO → Idade < 60? ├─ SIM → Adulto └─ NÃO → Idoso

⚠️ Detalhes Importantes

  • As chaves {} são opcionais se houver apenas UMA instrução
  • Sempre use chaves para evitar erros (boa prática)
  • Use == para comparação, não = para atribuição
  • Indente o código para melhor legibilidade
💡 Dica: Quando tiver múltiplas condições sobre a mesma variável (como no exemplo acima), use if-else if-else em vez de vários if separados. É mais eficiente!

3.2 Estrutura switch-case

🎛️ Quando Usar switch-case?

A estrutura switch-case é ideal quando você precisa comparar uma variável com múltiplos valores constantes. É mais limpa que vários if-else if.

📋 Sintaxe Básica

switch (expressão) {
    case valor1:
        // Código se expressão == valor1
        break;
    case valor2:
        // Código se expressão == valor2
        break;
    case valor3:
        // Código se expressão == valor3
        break;
    default:
        // Código se nenhum case corresponder
        break;
}

Exemplo - Menu de Operações:

#include <stdio.h>

int main() {
    int opcao;
    
    printf("=== MENU ===\n");
    printf("1. Soma\n");
    printf("2. Subtração\n");
    printf("3. Multiplicação\n");
    printf("4. Sair\n");
    printf("Escolha uma opção: ");
    scanf("%d", &opcao);
    
    switch (opcao) {
        case 1:
            printf("Você escolheu Soma\n");
            break;
        case 2:
            printf("Você escolheu Subtração\n");
            break;
        case 3:
            printf("Você escolheu Multiplicação\n");
            break;
        case 4:
            printf("Até logo!\n");
            break;
        default:
            printf("Opção inválida!\n");
            break;
    }
    
    return 0;
}

⚠️ A Importância do break

O comando break interrompe a execução e sai do switch. Se você esquecer, o código continuará executando o próximo case (fall-through).

Exemplo SEM break (errado):

switch (opcao) {
    case 1:
        printf("Um\n");
        // Falta break aqui!
    case 2:
        printf("Dois\n");
        break;
}

Se opcao = 1, a saída será:

Um
Dois

Isso geralmente NÃO é o que você quer!

✅ Exemplo COM break (correto):

switch (opcao) {
    case 1:
        printf("Um\n");
        break;
    case 2:
        printf("Dois\n");
        break;
}

Agora com opcao = 1, a saída será apenas:

Um

🎯 Múltiplos Cases com Mesmo Código

Você pode agrupar cases:

switch (dia) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        printf("Dia útil\n");
        break;
    case 6:
    case 7:
        printf("Fim de semana\n");
        break;
}
💡 Dica: Use switch-case quando comparar UMA variável com MÚLTIPLOS valores. Use if-else quando as condições forem mais complexas ou envolvam ranges.

3.3 Operador Ternário

❓ O que é o Operador Ternário?

O operador ternário (?:) é uma forma compacta de escrever um if-else. É útil para atribuições rápidas baseadas em uma condição.

📋 Sintaxe

variável = (condição) ? valor_se_verdadeiro : valor_se_falso;

📊 Comparação

Usando if-else:

int idade = 20;
int status;

if (idade >= 18) {
    status = 1;  // maior
} else {
    status = 0;  // menor
}

Usando operador ternário:

int idade = 20;
int status = (idade >= 18) ? 1 : 0;

💡 Exemplos Práticos

Exemplo 1: Maior entre dois números

#include <stdio.h>

int main() {
    int a = 10, b = 20;
    int maior = (a > b) ? a : b;
    
    printf("Maior: %d\n", maior);  // Saída: Maior: 20
    
    return 0;
}

Exemplo 2: Mensagem de Paridade

#include <stdio.h>

int main() {
    int numero = 7;
    char *tipo = (numero % 2 == 0) ? "par" : "ímpar";
    
    printf("%d é %s\n", numero, tipo);  // Saída: 7 é ímpar
    
    return 0;
}

Exemplo 3: Aninhado (menos recomendado)

int idade = 25;
char *categoria = (idade < 18) ? "menor" : 
                  (idade < 60) ? "adulto" : "idoso";

printf("Categoria: %s\n", categoria);
⚠️ Atenção: Ternários aninhados ficam difíceis de ler. Evite mais de um nível de aninhamento. Use if-else nesses casos.
💡 Dica: Use o operador ternário para atribuições simples e rápidas. Para lógica complexa, use if-else.

3.4 Estruturas de Controle Aninhadas

🎯 O que são Estruturas Aninhadas?

Estruturas aninhadas são aquelas dentro de outras. Você pode colocar um if dentro de outro if, um switch dentro de um if, etc.

📋 Exemplo 1: if dentro de if

#include <stdio.h>

int main() {
    int idade = 25;
    int renda = 3000;
    
    if (idade >= 18) {
        printf("Você é maior de idade\n");
        
        if (renda >= 2000) {
            printf("Você pode fazer um empréstimo\n");
        } else {
            printf("Renda insuficiente para empréstimo\n");
        }
    } else {
        printf("Você é menor de idade\n");
    }
    
    return 0;
}

Saída:

Você é maior de idade
Você pode fazer um empréstimo

📋 Exemplo 2: switch dentro de if

#include <stdio.h>

int main() {
    int mes = 3;
    
    if (mes >= 1 && mes <= 12) {
        switch (mes) {
            case 12:
            case 1:
            case 2:
                printf("Verão\n");
                break;
            case 3:
            case 4:
            case 5:
                printf("Outono\n");
                break;
            case 6:
            case 7:
            case 8:
                printf("Inverno\n");
                break;
            case 9:
            case 10:
            case 11:
                printf("Primavera\n");
                break;
        }
    } else {
        printf("Mês inválido\n");
    }
    
    return 0;
}

Saída: Outono

📋 Exemplo 3: Programa Completo - Validação de Nota

#include <stdio.h>

int main() {
    int nota;
    
    printf("Digite a nota (0-10): ");
    scanf("%d", ¬a);
    
    if (nota >= 0 && nota <= 10) {
        if (nota >= 9) {
            printf("Nota A - Excelente!\n");
        } else if (nota >= 7) {
            printf("Nota B - Bom!\n");
        } else if (nota >= 5) {
            printf("Nota C - Satisfatório\n");
        } else {
            printf("Nota F - Reprovado\n");
        }
    } else {
        printf("Nota inválida! Digite um valor entre 0 e 10\n");
    }

}

🎯 Boas Práticas

  • Indente corretamente (use 4 espaços ou 1 tab por nível)
  • Evite aninhamento muito profundo (máximo 3-4 níveis)
  • Se ficar complexo, considere usar funções
  • Adicione comentários em lógica complexa
EXEMPLO DE ANINHAMENTO: if (condição1) { ├─ if (condição2) { │ ├─ código │ └─ } ├─ else if (condição3) { │ ├─ código │ └─ } └─ } else { ├─ switch (variável) { │ ├─ case 1: ... break; │ ├─ case 2: ... break; │ └─ } └─ }
